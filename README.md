# Searchlight Riddle Compass

These add a POST endpoint at /api/solve that accepts { "riddle": "..." } and returns { "answer": "CODE" } using the Lovable AI Gateway with Google Search."

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://searchlight-riddle-compass.lovable.app
